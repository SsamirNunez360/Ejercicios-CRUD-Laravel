# Control de Tareas — CRUD en Laravel 13

Aplicación web desarrollada en **Laravel 13** con autenticación de usuarios y operaciones completas de creación, lectura, actualización y eliminación (**CRUD**) sobre el módulo de tareas.

## Requisitos previos

- **PHP** >= 8.2 (con extensiones `pdo_mysql`, `mbstring`, `openssl`, `tokenizer`, `xml`, `ctype`, `json`)
- **Composer**
- **MySQL / MariaDB** (puerto `3306`, compatible con XAMPP)
